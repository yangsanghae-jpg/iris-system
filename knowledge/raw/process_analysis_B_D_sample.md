## 0. 라우팅 타입 한눈에 보기

| 코드 | 명칭 | 흐름 | 대표 사례 |
|------|------|------|----------|
| `RT_LINE` | 라인형 (Linear) | 고정 순서로 직선 진행, 반복 없음 | 솔라셀, 2차전지 셀 라인 |
| `RT_BATCH` | 배치형 (Batch) | 로트(batch) 단위 가공·열처리·이송 | 반도체 후공정 패키징·테스트 |
| `RT_REENTRANT` | 재진입형 (Reentrant) | 동일 공정/설비를 여러 번 다시 통과 | 웨이퍼 팹(포토→식각→박막의 반복) |
| `RT_PROJECT` | 프로젝트형 (Project) | 1건당 계획·자원·납기 관리 | ESS 사이트 구축 |

> 라우팅이 다르면 **계획 방식·재고 형태·KPI 정의·시스템 우선순위**가 전부 달라집니다. 같은 "반도체"라도 팹과 패키징은 다른 세계입니다.

# B. 반도체 제조 / 半导体制造

> 산업의 성격: 강한 설비 제약 + 다수의 재진입 + 수율이 매출을 결정. **공정 별 시스템 요구 격차가 가장 큰 산업.**

## B-1. 로직 / 파운드리 (`logic_foundry` / 逻辑·代工)

- **공정 흐름**: 포토 → 식각 → 박막 증착 → CMP → 이온주입 (재진입)
- **라우팅**: `RT_REENTRANT` — 박막/포토 모듈을 8~30번 다시 통과
- **현장 특성**: WIP 한 로트가 팹을 도는 데 수 주, 동일 설비에 여러 세대 디바이스가 섞임. 디스패칭 룰이 사이클 타임의 30~50%를 좌우.
- **주요 관리점**:
  - 로트 추적 (Lot Track) — 24/7 단위, 단계별 위치/이력 100% 기록
  - WIP 가시화 — 공정 단계별 재공·대기/가공 분리, 병목 감지
  - 룰 기반 디스패치 — 우선순위 룰(납기·핫로트·setup) 자동 적용
  - 레시피 제어 — 장비 ↔ 제품 ↔ 공정 조건 일치 검증
  - 수율 모니터링 — In-line 측정·결함 맵 자동 집계
  - 알람 폐루프 — 이상 발생 → 디스패치 보류 → 조치 → 재가동까지 자동 폐쇄
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성
- **시스템 방향성**: Dispatch / WIP / CT 최적화

## B-2. 메모리 DRAM·NAND (`memory_dram_nand` / 存储)

- **공정 흐름**: 셀 어레이 → 주변회로 → 다층 적층 (3D NAND) → KGD 어셈블리
- **라우틨**: `RT_REENTRANT` — 셀·주변회로 반복, NAND는 100층 이상 적층 시퀀스
- **현장 특성**: 동일 디바이스 대량 생산이라 변동이 작고, **수율·캐파 회수율**이 곧 경쟁력. 적층 공정의 단계별 정렬·결함이 누적되므로 폐루프 측정이 필수.
- **주요 관리점**: 로직과 동일(로트 추적·WIP 가시화·룰 디스패치·레시피·수율·알람 폐루프). 추가로 적층 단계별 **막두께 SPC**가 핵심.
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성
- **시스템 방향성**: Dispatch / WIP / CT

## B-3. 아날로그·혼성신호 (`analog_mixed` / 模拟·混合信号)

- **공정 흐름**: 웨이퍼 가공 → 트림·캘리브레이션 → 패키지 → 테스트
- **라우팅**: `RT_REENTRANT` — 디지털 대비 적지만 모듈/트림 단계 반복
- **현장 특성**: **소품종 다공정·고변동**. 트림 캘리브레이션이 곧 품질이며, 테스트 단계에서 디바이스마다 다른 시퀀스를 가짐.
- **주요 관리점**: 로트 추적·레시피 제어를 특히 강하게 가져가야 함 (제품별 트림 파라미터가 1차 합격률에 직결).
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성
- **시스템 방향성**: Dispatch / WIP / CT

## B-4. 전력·디스크리트 (`power_discrete` / 功率·分立)

- **공정 흐름**: 에피택시 → 단위 소자 가공 → 패키지 → 번인
- **라우팅**: `RT_BATCH` — 에피·번인 같은 배치 열처리 위주
- **현장 특성**: **소자 한 종류씩 대량 배치 처리**. 에피택시 반응로의 가스 변경·온도 프로파일이 곧 품질이라 레시피 변경 이력이 감사 자료가 됨.
- **주요 관리점**: 트레이서빌리티(원자재 → 에피 ↔ 단위 소자 → 패키지 단위), 레시피 버전 관리, 번인 패스/페일 기록
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성
- **시스템 방향성**: Traceability / Recipe / Quality

## B-5. 광·센서 (`optical_sensor` / 光学·传感)

- **공정 흐름**: 박막 증착 → 광학 정렬 → 다이싱 → 패키지
- **라우팅**: `RT_REENTRANT` — 박막·광학 정렬 반복
- **현장 특성**: **정렬 오차가 수율의 결정 인자**. 다이싱 단계에서 결함 위치를 다시 매핑해 패키지 단계로 전달해야 함 (디바이스 단위 트레이서빌리티).
- **주요 관리점**: 로트 추적·수율·디스패치 + **1차 합격률(FPY)** 별도 관리
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성, **1차 합격률**
- **시스템 방향성**: Dispatch / WIP / CT

## B-6. 화합물 반도체 SiC/GaN (`compound_semi` / 化合物半导体)

- **공정 흐름**: 단결정 성장 → 슬라이싱 → 에피 → 디바이스 가공
- **라우팅**: `RT_BATCH` — 결정 성장(주~월) + 에피 배치 처리
- **현장 특성**: **사이클이 길고 결함이 누적적**. 단결정 1배치 → 슬라이스 수십~수백 장 → 에피 결함이 디바이스로 전파됨. 원자재 트레이서빌리티가 곧 품질 책임 추적.
- **주요 관리점**: 트레이서빌리티(결정 lot → 웨이퍼 ID → 디바이스), 레시피, 품질
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성, **1차 합격률**
- **시스템 방향성**: Traceability / Recipe / Quality

## B-7. 조립·패키징 (`assembly_packaging` / 封装) — OSAT

- **공정 흐름**: 다이 어태치 → 와이어/플립칩 본딩 → 몰딩 → 마킹·테스트
- **라우팅**: `RT_BATCH` — 스트립/매거진 단위 배치 흐름
- **현장 특성**: **다품종·짧은 셋업 사이클**. 한 라인이 하루에 5~10 종 제품을 교번. 셋업·라인 전환 시간이 곧 생산성이며, 라인 밸런스가 OEE에 직격.
- **주요 관리점**: 로트(스트립) 추적, 셋업·전환 표준작업, 라인 밸런스, 마킹·시리얼 트레이서빌리티
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성, **라인 밸런스**
- **시스템 방향성**: Traceability / Recipe / Quality

## B-8. 테스트 (`test` / 测试)

- **공정 흐름**: 프로브 테스트 → 번인 → 최종 테스트·분류
- **라우팅**: `RT_BATCH` — 핸들러·번인 보드 단위 묶음 처리
- **현장 특성**: **테스트 시간 = 비용**. 패턴별 테스트 시간 차가 크고, 분류(bin) 결과가 즉시 그레이드/판가에 연결. 번인 보드 가용성이 캐파를 좌우.
- **주요 관리점**: 디바이스 시리얼 단위 결과 추적, 번인 자원 스케줄링, bin 분포 SPC
- **KPI**: 수율, 사이클 타임, WIP 회전율, 디스패치 안정성, **1차 합격률**
- **시스템 방향성**: Traceability / Recipe / Quality

# D. 디스플레이·신에너지 제조 / 面板与新能源制造

> 산업의 성격: **대규모 라인 + 막두께·온도·압력 같은 공정 파라미터 안정성**이 곧 수율. 일부(ESS)는 프로젝트형으로 갈라짐.

## D-1. LCD (`lcd` / LCD)

- **공정 흐름**: 기판 세정 → TFT 박막 → 컬러필터 → 셀 합착 → 모듈 조립
- **라우팅**: `RT_LINE` — 대형 기판이 직선 라인을 한 번에 통과
- **현장 특성**: **대형 기판(>2m) 한 장의 가치가 큼**. 라인 정지 = 즉시 손실. 박막 두께·합착 정밀도가 수율 결정 인자이며, 모듈 조립은 거의 별도의 다운스트림 라인.
- **주요 관리점**: 배치(라인) 추적, WIP 가시화, **공정 모니터링(SPC)**, 수율, 라인 가시화
- **KPI**: 수율, OEE, 산출량, 공정 안정성, **라인 밸런스**
- **시스템 방향성**: Visibility / Efficiency

## D-2. OLED (`oled` / OLED)

- **공정 흐름**: 기판 세정 → LTPS/LTPO TFT → OLED 증착 → 인캡슐레이션 → 모듈
- **라우팅**: `RT_REENTRANT` — OLED 증착·TFT 단계가 재진입형 마스크 정렬 반복
- **현장 특성**: **LCD보다 한 단계 더 복잡**. 유기 재료 증착 챔버는 환경(진공·온도·시간)에 매우 민감. WIP가 챔버를 다시 통과하는 시퀀스가 있어 사이클 타임 관리가 핵심.
- **주요 관리점**: 배치 추적, WIP 가시화, 공정 모니터링, 수율
- **KPI**: 수율, OEE, 산출량, 공정 안정성
- **시스템 방향성**: Dispatch / WIP / CT  ← LCD와 다른 지점

## D-3. 태양광 (`solar_pv` / 太阳能光伏)

- **공정 흐름**: 잉곳 → 웨이퍼 → 셀 텍스처/도핑 → 모듈 라미네이션
- **라우팅**: `RT_LINE` — 셀 라인이 분당 수천 장 직선 처리
- **현장 특성**: **셀 1장 단가는 낮지만 라인 속도가 매우 높음**. 1% 수율 차이가 GWh 단위에서 거대한 매출 차이가 됨. 도핑·텍스처 공정 파라미터의 일관성이 곧 수율.
- **주요 관리점**: 배치 추적, WIP 가시화, **공정 모니터링(SPC)**, 수율, 라인 가시화
- **KPI**: 수율, OEE, 산출량, 공정 안정성
- **시스템 방향성**: Visibility / Efficiency

## D-4. 2차전지 (`battery` / 二次电池)

- **공정 흐름**: 전극 코팅 → 압연·노칭 → 권취/적층 → 활성화·포메이션
- **라우팅**: `RT_LINE` — 전극 → 조립 → 활성화의 직선 라인
- **현장 특성**: **포메이션이 사이클 타임의 50% 이상**. 셀 1개당 시리얼 추적이 안전·리콜 요건. 전극 코팅 두께·균일도가 첫 단계에서 결정.
- **주요 관리점**: 배치(롤) 추적, WIP 가시화, 공정 모니터링, 수율
- **KPI**: 수율, OEE, 산출량, 공정 안정성
- **시스템 방향성**: Visibility / Efficiency

## D-5. ESS 에너지 저장 시스템 (`energy_storage` / ESS 储能系统)

- **공정 흐름**: 셀 → 모듈 → PCS/EMS 통합 → 사이트 설치·시운전
- **라우팅**: `RT_PROJECT` — 사이트 단위 프로젝트
- **현장 특성**: **앞 단계는 라인형 제조, 뒤 단계는 프로젝트형 EPC**. 사이트마다 사양·인허가·시운전이 달라 납기 관리가 본질. 셀/모듈 추적은 안전·보증 의무.
- **주요 관리점**: 배치 추적, WIP 가시화, 공정 모니터링, 수율, **진척 모니터링(프로젝트)**
- **KPI**: 수율, OEE, 산출량, 공정 안정성, **프로젝트 진척**
- **시스템 방향성**: Order / Resource / Delivery  ← 라인 4종과 완전히 다름

### D 산업 종합 — 한 화면 정리

| 세부 산업 | 라우팅 | 추가 KPI | 시스템 우선 |
|-----------|--------|----------|-------------|
| LCD | Linear | 라인 밸런스 | Visibility / Efficiency |
| OLED | Reentrant | — | Dispatch / WIP / CT |
| 태양광 | Linear | — | Visibility / Efficiency |
| 2차전지 | Linear | — | Visibility / Efficiency |
| ESS | Project | 프로젝트 진척 | Order / Resource / Delivery |

> **핵심 통찰**: D 산업 5개 중 4개가 라인형이지만 **OLED는 Reentrant, ESS는 Project**로 따로 떨어집니다. "디스플레이·신에너지" 한 묶음으로 동일 시스템을 추천하면 OLED와 ESS는 헛다리. Step5 추천은 **세부 산업 라우팅을 1차 분기점**으로 두어야 합니다.

## 종합 시사점

1. **라우팅이 시스템 추천의 1차 분기**: 같은 산업 안에서도 라우팅이 다르면 MVP 기능·핵심 모듈·KPI 우선이 전혀 다름 (반도체 전/후공정, OLED vs LCD, ESS vs 셀).
2. **재진입 = Dispatch/WIP/CT, 배치 = Traceability/Recipe/Quality, 라인 = Visibility/Efficiency, 프로젝트 = Order/Resource/Delivery** — 이 4분면이 결정론적으로 유효.
3. **공통 KPI**(수율·OEE)는 데이터 수집의 ABC. 추가 KPI(라인 밸런스·1차 합격률·프로젝트 진척)가 그 세부 산업의 진짜 색깔.
4. **Step5 「1.1 공정 분석」 카드**는 위 표 형식을 그대로 빌려와 — 선택된 세부 산업 하나에 대해 (공정 흐름 / 라우팅 / 추가 KPI / 시스템 우선) 4개 슬롯만 표시하면 충분.
