Cursor 작업 규칙 (강제)

1. 작업 범위
	•	항상 기존 파일만 수정한다
	•	새 파일 생성 금지 (명시적 요청 제외)

2. 금지 사항
	•	playwright 사용 금지
	•	npm / npx 실행 금지
	•	shell command 실행 금지
	•	테스트/스크립트 자동 생성 금지

3. 수정 원칙
	•	한 번에 한 영역만 수정
	•	UI 구조 / 데이터 / 서버를 동시에 수정하지 않는다
	•	기존 동작을 깨지 않는다

4. Card 작업 규칙
	•	Card 구조 변경 시 반드시 panel 단위로 분리한다
	•	section 분리는 허용되지 않는다

5. 파일 제한
	•	요청에 명시된 파일만 수정한다

6. 검증 기준
	•	DOM 기준으로 판단한다
	•	visual이 아닌 구조 기준으로 성공/실패 판단

⸻

추가 규칙
	•	모든 보고서는 /docs 경로에 생성한다
	•	보고 시 반드시 파일 링크를 함께 제공한다
	•	Git 커밋 시:
	•	태그에 날짜/시간/작업 내용을 포함한다
	•	모든 결과는 하나의 문서에서 이력 관리한다
