# LN/LT 单晶薄膜光电子半导体企业（Nanoln）生产运营指标完整结构体系

## 体系设计总说明

本体系针对**济南晶正电子（Nanoln）铌酸锂（LN）/ 钽酸锂（LT）单晶薄膜基板、光电子半导体精密加工核心业务**设计，区别于普通量产型半导体晶圆厂，核心聚焦「高精度薄膜品质稳定性、高价值原料损失管控、长工艺周期交付履约、多品种小批量瓶颈产能管控」四大核心业务诉求。

指标严格分层，**自上而下战略分解、自下而上溯源追责**，逻辑为：

> 经营层决策 cockpit（L0）→ L1 公司最终成果指标 → L2 IE 端到端流程溯源指标 → L3 部门责任拆解指标 → L4 现场原始执行 / 溯源指标

同时跨层整合**质量、设备、交付、工艺**等特定领域专项指标，实现「结果 - 流程 - 责任 - 现场 - 专项」全链路追溯。

## 1. 公司核心成果指标（L1）

定位：面向经营层的**最终战略结果指标**，用于判断公司生产运营是否达成业务目标，不关注过程，只关注最终绩效，分为 5 大维度，共 13 项核心指标。



| 维度          | 指标名称             | 指标定义                                                         | 业务核心意义                           | 数据来源                    |
| ----------- | ---------------- | ------------------------------------------------------------ | -------------------------------- | ----------------------- |
| **交付履约维度**  | 关键客户订单及时交付率（OTD） | 月度 / 季度核心战略客户（光通信调制器、红外传感头部企业）订单按约定交货期的准时交付比例，不含因客户规格变更导致的延期 | 体现对高价值核心供应链的交付保障能力，是客户留存的核心指标    | ERP/MES 出货记录、订单管理模块     |
| **交付履约维度**  | 订单交付风险预警数        | 识别后道工序堵塞、品质判定延迟、设备异常影响的预期延期订单数量                              | 提前干预交付瓶颈，避免重大客户投诉                | MES-WIP 模块、品质异常模块       |
| **精密品质维度**  | 客户规格一次合格率        | 成品在出货检验中，完全符合客户图纸 / 标准中**厚度均匀性、表面粗糙度、颗粒度、晶格偏移**全项特殊特性要求的批次比例 | 核心品质竞争力，直接关联客户量产合格性及后续订单         | MES 全检记录、SPC 统计过程控制系统   |
| **精密品质维度**  | 薄膜厚度均匀性稳定率       | 实测晶圆表面厚度偏差≤±1μm（可按客户规格调整）的合格批次占总生产批次比例                       | LN/LT 薄膜的最核心工艺指标，直接决定后道光电子器件封装良率 | 精密测厚仪数据、SPC 系统          |
| **精密品质维度**  | 表面缺陷不良率          | 因表面划痕、崩边、颗粒残留、点缺陷导致的不合格成品数占总检验数比例                            | 管控精密加工过程中的表观品质缺陷，是高端客户重点抽检项目     | 高倍表面检测仪数据、MES 不良录入模块    |
| **高价值损失维度** | 原料报废损失率          | 月度 LN/LT 单晶基板原料报废数量占总投入原料数量的比例（换算为片数 / 金额，体现高价值原料损耗）         | 管控核心成本，LN/LT 单晶原料成本占生产成本 60% 以上  | MES 投料记录、ERP 成本模块、报废单   |
| **高价值损失维度** | 重工返修率            | 需重新抛光、去膜、再加工的成品批次占总投产批次的比例                                   | 减少额外工艺产能占用，降低二次品质风险              | MES 工艺流转卡、返修记录          |
| **高价值损失维度** | 异常质量成本占比         | 报废、返修、客户退货、重工产生的额外成本占月度生产总成本比例                               | 量化品质异常对盈利的直接影响                   | ERP 财务模块、品质不良台账         |
| **瓶颈产能维度**  | 核心工序产能利用率        | 瓶颈工序（薄膜沉积、精密切割、化学机械抛光 CMP）实际投入工时占计划可用工时的比例                   | 识别当前生产能力约束，评估交付履约上限              | MES 设备运行记录、产能计划模块       |
| **瓶颈产能维度**  | 瓶颈工序在制品（WIP）滞留量  | 等待进入瓶颈工序的待加工晶圆批次 / 数量                                        | 定位前端工序投料不合理导致的瓶颈堵塞风险             | MES-WIP 实时监控模块          |
| **改进闭环维度**  | 质量异常闭环完成率        | 月度产生的品质异常（含客户投诉、IPQC 巡检异常）按要求完成纠正预防措施（CAPA）关闭的比例             | 评估问题根治能力，避免同类品质重复发生              | MES 异常模块、CAPA 管理系统      |
| **改进闭环维度**  | 设备故障重复发生率        | 同一台设备同一种故障月度重复发生的次数占总故障次数的比例                                 | 评估设备维修根治能力，减少非计划停机对交付 / 品质的影响    | MES 设备维护模块、EAM 企业资产管理系统 |
| **改进闭环维度**  | 工艺参数稳定率          | 工艺参数（沉积温度、抛光压力、镀膜速率）未偏离管控上下限的生产批次占总批次比例                      | 体现工艺成熟度，保障不同量产批次的品质一致性           | SPC 系统、MES 工艺参数记录模块     |

## 2. IE 基于运营流程指标（L2）

定位：用**工业工程（IE）流程拆解视角**，端到端拆解订单流转、生产加工、品质判定、设备运行、物料供应的全流程浪费，用来溯源 L1 指标结果的过程原因，识别堵塞、等待、过长工艺周期等非增值浪费。

### 2.1 订单端到端流程指标



| 指标名称         | 指标定义                                  | IE 管理用途              |
| ------------ | ------------------------------------- | -------------------- |
| 订单整体生产周期（CT） | 从订单投料第一道工序到成品入库的日历周期时长（含工序等待、检验、滞留时间） | 评估整体生产效率，定位周期过长的核心环节 |
| 订单核准周期偏差率    | 实际生产周期与标准工艺周期的差异比例                    | 识别计划排程与实际现场执行的偏差     |
| 订单工序流转准时率    | 每批产品按工艺计划准时流转到下道工序的比例                 | 识别工序间流转的衔接浪费         |

### 2.2 在制品（WIP）流转流程指标



| 指标名称               | 指标定义                             | IE 管理用途              |
| ------------------ | -------------------------------- | -------------------- |
| 工序排队时间（Queue Time） | 批次在工序 Begin 前的等待时长，不包含实际加工时间     | 识别前端投料不均、瓶颈工序负荷过载的浪费 |
| WIP 滞留工序分布         | 统计各工序停留 WIP 数量、滞留时长超过 48h 的批次明细  | 精准定位生产流程堵塞的具体工序      |
| WIP 批次流转顺畅率        | 无停顿、无加急、无临时调整按正常工艺路线流转的 WIP 批次比例 | 评估生产计划排程的合理性         |

### 2.3 瓶颈产能负荷流程指标



| 指标名称            | 指标定义                        | IE 管理用途            |
| --------------- | --------------------------- | ------------------ |
| 瓶颈工序负荷率         | 瓶颈工序实际接收加工任务量与最大可用产能的比例     | 评估产能瓶颈对整体交付的约束程度   |
| 瓶颈工序前后道 WIP 平衡率 | 瓶颈工序前待加工 WIP 数量与后道接收能力的匹配比例 | 优化投料节奏，避免瓶颈缺料或过载堵塞 |
| 关键设备有效利用率       | 瓶颈设备实际加工晶圆时长与计划开机时长的比例      | 剔除设备空转、待料、换型的时间损失  |

### 2.4 品质判定流转流程指标



| 指标名称     | 指标定义                         | IE 管理用途            |
| -------- | ---------------------------- | ------------------ |
| 品质检验停留时长 | 批次完成加工后等待检验、品质判定的滞留时长        | 识别品质检验 / 判定环节的流程瓶颈 |
| 不合格品处理周期 | 从判定不合格到确定返工 / 报废 / 特采的审批处理时长 | 减少不合格品占用的工序产能      |
| 首件确认周期时长 | 每班 / 每批次生产前首件送检到品质确认完成的时长    | 减少待料停机时间损失         |

### 2.5 设备状态运维流程指标



| 指标名称              | 指标定义                    | IE 管理用途             |
| ----------------- | ----------------------- | ------------------- |
| 设备平均修复时间（MTTR）    | 设备从故障停机到修复完成、恢复生产的平均用时  | 评估设备运维的应急响应能力       |
| 设备平均无故障运行时间（MTBF） | 设备两次相邻故障间的正常运行平均时长      | 评估核心设备的运行稳定性、预判故障风险 |
| 预防性保养（PM）计划完成率    | 按维护计划完成的设备保养次数占总计划次数的比例 | 验证预防性保养的执行效果        |

### 2.6 原物料投入消耗流程指标



| 指标名称      | 指标定义                                 | IE 管理用途             |
| --------- | ------------------------------------ | ------------------- |
| 原料齐套准时率   | 生产计划开工日期，对应订单所需 LN/LT 基板原料、辅材齐套到位的比例 | 评估供应链对生产开工的保障能力     |
| 物料批次追溯准确率 | 实际生产用料批次与系统 BOM、投料记录的对应匹配比例          | 确保不良物料精准溯源，避免批量品质事故 |
| 辅料单位消耗量   | 每加工完成一片合格晶圆对应的抛光液、靶材等辅料消耗数量          | 识别辅料使用过程中的成本浪费      |

## 4. 现场执行指标（L4）

定位：**车间现场原始采集数据点**，是 L1-L3 所有指标的底层数据来源，用于现场人员实时异常识别、上层指标问题根因溯源。按现场采集对象分类，每个数据点明确采集频率、用途及关联上层指标。

### 4.1 订单批次流转溯源数据



| 现场数据点                | 采集频率               | 溯源 / 执行用途              | 关联上层指标            |
| -------------------- | ------------------ | ---------------------- | ----------------- |
| 订单编号、客户名称、产品型号、要求交货期 | 批次创建时采集一次          | 精准定位订单对应的生产现场，跟踪订单执行进度 | 关键客户 OTD、交付风险预警数  |
| 当前加工工序编号、工序名称、所在设备编号 | 工序流转时实时采集          | 定位 WIP 实际滞留位置，排查订单延期原因 | WIP 滞留工序分布、订单生产周期 |
| 工序实际开始加工时间、实际完成时间    | 工序 begin/end 时实时采集 | 计算工序加工时长、排队时长，识别流程浪费   | 工序排队时间、订单整体生产周期   |
| 工序流转检验结果、转运操作人员 ID   | 工序流转时采集            | 排查工序间不良传递的责任环节         | 工序流转准时率、不合格品处理周期  |

## 7. 体系落地注意事项



1. **避免普通半导体工厂的指标照搬**：LN/LT 单晶薄膜核心竞争力是**高精度工艺稳定性**而非量产规模，因此绝不盲目追求设备综合效率（OEE）、量产节拍时间（TT）等普通制造指标，优先品质追溯、降损、交付能力

2. **循序渐进，允许手工采集过渡**：初期不强行推动全自动化数据采集，对未接入 MES/SPC 的设备，允许 Excel 手工录入作为补充，待运行稳定后，逐步打通设备 PLC、检测仪器、MES、ERP 数据链路

3. **指标定位为改进工具，而非单纯考核依据**：设计指标的核心目的是**溯源问题根因**，而非单纯处罚部门，例如：工序报废率升高，必须定位到具体原料批次、设备、工艺参数，而非只考核生产部门

4. **定期迭代指标，匹配业务发展**：根据客户新规格要求、工艺技术迭代、量产产品类型变化，每季度 review 指标适用性，及时调整厚度均匀性、颗粒度等特殊特性管控标准

> 本体系完全适配 Nanoln LN/LT 单晶薄膜生产工艺特性，覆盖经营决策、流程优化、部门管理、现场溯源全链路，实现「看数、溯源、改问题」的管理闭环，支撑企业核心技术竞争力稳定输出。
