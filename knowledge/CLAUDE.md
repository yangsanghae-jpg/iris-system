# LLM Wiki Rules (IRIS)

## Role
This system converts raw data into structured knowledge.

## Hard Rules
- Never modify files in /raw
- Only write to /wiki
- Use markdown
- Prefer Korean unless source material requires another language
- Use [[links]] between related concepts
- Avoid duplicate pages
- Keep facts grounded in the raw source
- Do not make execution decisions
- Do not modify code repositories

## Page Structure
Each page should contain:
- Title
- Summary
- Key Concepts
- Related Links
- Source Notes

## Behavior
- New concept -> create page
- Existing concept -> update page carefully
- Preserve useful prior content when updating
- Connect related topics with [[links]]
